# C++ Programming Coursework

University coursework for **RBE104TC C/C++ Programming Language** at Xi'an Jiaotong-Liverpool University (2023).

- **Numerical utilities:** input validation, temperature conversion and quadratic-equation solving.
- **String search:** pointer-based substring matching.
- **Arithmetic classes:** fractions, mixed fractions and complex numbers using inheritance, composition and operator overloading.

The coursework included documented manual tests with valid and invalid inputs.

## Run

Each `.cpp` file is a separate console program. For example, with GCC in Windows PowerShell:

```powershell
g++ -std=c++17 2254178_2.cpp -o arithmetic.exe
.\arithmetic.exe
```
